# Mollo → Rivals 2

Documentation of a non-commercial fan port of **Mollo** (created by Giik, property of Aether Studios) to the Rivals of Aether II Workshop, built with Claude Code.

- [Home](https://tidianetone.github.io/mollo-r2/)
- [Build report](https://tidianetone.github.io/mollo-r2/rapport.html)
- [Beginner guide](https://tidianetone.github.io/mollo-r2/guide.html) ([PDF](Mollo_Rivals2_guide.pdf))
- [Attack sheet](https://tidianetone.github.io/mollo-r2/attaques.html)

The mod files themselves are not distributed here. Frame data: [Rivals Academy](https://rivals.academy/library/mollo/).
